# WFS-SMC Weekly Services Record App

A browser-based weekly services recording application for Wesina Financial Services-SMC Limited.

## Features
- Daily entry for printing, photocopying, photography, document and online services
- Automatic daily, weekly, expense and net-collection totals
- Local browser saving
- JSON import and export
- Print and Save as PDF
- Responsive layout for desktop and mobile
- No database or external dependency

## Publish with GitHub Pages
1. Upload `index.html` to the root of the repository.
2. Open **Settings > Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Save and wait for GitHub Pages to publish the site.

## Important security note
This version stores records in the user's browser. Do not enter customer personal data, passwords, PINs, API keys, account credentials, or confidential financial information.
